# M1 — Scene Graph & Static Renderer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render a static JSON scene graph (primitive meshes with transforms) into a React Three Fiber viewport, with no AI and no tools — proving the scene graph schema and the rendering pipeline.

**Architecture:** pnpm workspace monorepo. `packages/scene-engine` holds the scene schema (TypeScript types) and a sample scene — framework-agnostic, no React dependency. `apps/web` is a Next.js 15 App Router app that loads the scene into a Zustand store and renders it declaratively with React Three Fiber.

**Tech Stack:** pnpm workspaces, TypeScript 5, Next.js 15 (App Router), React Three Fiber v10, @react-three/drei (OrbitControls only), Three.js, Zustand v5, vitest (scene-engine only).

**Ponytail scope cuts (explicit, do NOT build in M1):**
- No Zod — deferred to M2 (tool parameter validation)
- No `llm-adapter` package — deferred to M3
- No `schema` package — types live in `scene-engine/src/types.ts` for M1
- No zundo (undo middleware) — deferred to M4
- No Dexie / IndexedDB persistence — deferred
- No Tailwind — deferred to M4 UI work; use plain CSS
- No three-bvh-csg (boolean ops) — deferred to M2
- No test framework in `apps/web` for M1 — R3F canvas is plumbing, verified manually in browser
- Only primitive mesh types (`box` / `sphere` / `cylinder` / `plane` / `group`); template types (`house`, `tree`, `road`) come in M3 via tool executors

```typescript
export type Vec3 = [number, number, number];

export type Transform = {
  position: Vec3;
  rotation: Vec3;
  scale: Vec3;
};

export type Material = {
  color: string; // hex string e.g. "#8b5cf6"
};

// M1: primitive meshes + grouping. Template types (house/tree/road) added in M3.
export type PrimitiveMeshType = "box" | "sphere" | "cylinder" | "plane";
export type GroupType = "group";
export type SceneNodeType = PrimitiveMeshType | GroupType;

// Loose by design for M1 — Zod schema in M2 will tighten this per-type.
export type SceneNodeParameters = Record<string, number | number[] | string>;

export type SceneNode = {
  id: string;
  type: SceneNodeType;
  name: string;
  transform: Transform;
  parameters: SceneNodeParameters;
  material?: Material;
  children: SceneNode[];
};

export type Scene = {
  version: string;
  nodes: SceneNode[];
};
```

## Task 6: Build R3F Viewport Component

**Files:**
- Create: `apps/web/src/components/Viewport.tsx`

- [ ] **Step 6.1: Create `src/components/Viewport.tsx`**

```tsx
"use client";

import { Canvas } from "@react-three/fiber";
import { OrbitControls } from "@react-three/drei";
import type { SceneNode, Vec3 } from "@asset-studio/scene-engine";
import { useSceneStore } from "../store/sceneStore";

function PrimitiveGeometry({ node }: { node: SceneNode }) {
  const p = node.parameters;
  switch (node.type) {
    case "box":
      return <boxGeometry args={(p.size as Vec3) ?? [1, 1, 1]} />;
    case "sphere":
      return <sphereGeometry args={[(p.radius as number) ?? 1, 32, 32]} />;
    case "cylinder":
      return (
        <cylinderGeometry
          args={[
            (p.radiusTop as number) ?? 0.5,
            (p.radiusBottom as number) ?? 0.5,
            (p.height as number) ?? 1,
            32,
          ]}
        />
      );
    case "plane":
      return (
        <planeGeometry
          args={[(p.width as number) ?? 1, (p.height as number) ?? 1]}
        />
      );
    default:
      return null;
  }
}

function NodeMesh({ node }: { node: SceneNode }) {
  const { position, rotation, scale } = node.transform;

  if (node.type === "group") {
    return (
      <group position={position} rotation={rotation} scale={scale}>
        {node.children.map((child) => (
          <NodeMesh key={child.id} node={child} />
        ))}
      </group>
    );
  }

  return (
    <mesh position={position} rotation={rotation} scale={scale}>
      <PrimitiveGeometry node={node} />
      <meshStandardMaterial color={node.material?.color ?? "#888888"} />
    </mesh>
  );
}

export default function Viewport() {
  const scene = useSceneStore((s) => s.scene);

  return (
    <Canvas camera={{ position: [6, 5, 6], fov: 50 }}>
      <ambientLight intensity={0.6} />
      <directionalLight position={[10, 10, 5]} intensity={1} />
      {scene.nodes.map((node) => (
        <NodeMesh key={node.id} node={node} />
      ))}
      <OrbitControls makeDefault />
    </Canvas>
  );
}
```

> Source: R3F `<Canvas>`, `<mesh>`, nested `<group>` declarative primitives confirmed via context7 `/pmndrs/react-three-fiber`. `OrbitControls` via `@react-three/drei`.
